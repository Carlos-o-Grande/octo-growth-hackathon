# Octo poses

16 poses of the Octo character, PNG with transparent background, 1200 x 1200. Web-size copies (400 x 400) for the landing page are in [`outputs/website/landing/media/poses/`](../../outputs/website/landing/media/poses/).

| File | Use it for |
|---|---|
| `01-neutral.png` | Default, logo-like spots |
| `02-happy.png` | Success, end cards |
| `03-wink.png` | Playful CTAs, retargeting |
| `04-blink-calm.png` | "Quiet until you call it" |
| `05-look-left.png`, `06-look-right.png` | Next to text: Octo looks at the line |
| `07-look-up.png` | Looking at a headline above |
| `08-surprised.png` | Problem slides ("nobody wrote it down?") |
| `09-listening.png` | On the call, listening |
| `10-talking.png` | Octo answering, the Monday review |
| `11-thinking.png` | Working on an answer |
| `12-task-done.png` | Task updated, "just talk" |
| `13-task-card.png` | Tasks by DM, the PM you don't have |
| `14-calendar.png` | Booking a meeting, the brief before the call |
| `15-on-call-tile.png` | Octo on its own video tile |
| `16-bounce.png` | Energy, launch moments |
| `contact-sheet.png`, `contact-sheet-dark.png` | All poses at a glance |

Drawn in code from the original `assets/screenshots/octo-mascot.png`; source and re-render command in [`growth-kit/outputs/creative/octo-poses/source/`](../../growth-kit/outputs/creative/octo-poses/source/). The character belongs to Octocrew: hackathon landing and drafts are fine; ask Oleksii before using the poses in public posts or ads.
